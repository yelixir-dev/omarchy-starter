01 · 선택

OMO 코딩 에이전트 설치

코딩 에이전트는 터미널에서 대화하듯 명령을 내릴 수 있는 AI 도구입니다. "한글 입력기를 설치해줘"처럼 말하면 명령을 대신 만들고 실행해 줍니다. 리눅스가 처음이라면 모든 설치를 이런 에이전트에게 맡길 수도 있습니다. 이 안내서의 "AI에게 맡기기" 프롬프트가 바로 그 용도입니다. 단, 에이전트 설치 자체는 부탁할 에이전트가 아직 없으니, 이 장만큼은 아래 명령어를 직접 따라 하면 됩니다. 설치가 끝나면 다음 장부터는 OMO에게 맡길 수 있습니다.

OMO는 이런 에이전트 중 하나이며 선택 사항입니다. 이미 쓰는 AI 도구가 있다면 그대로 사용해도 좋습니다.

직접 설치하기

npm으로 설치하고 로그인합니다

먼저 터미널을 여세요. 키보드에서 Super + Enter를 누르시면 터미널이 열립니다. Mac 키보드라면 Command 키가 Super 키입니다.

터미널에서 아래 명령을 한 줄씩 실행하세요.

npm i -g omo-ai@beta
omo

OMO 화면이 열리면 입력창에 다음을 입력하고 안내에 따라 인증합니다.

/login

인증 후에는 작업할 폴더에서 omo를 실행하면 됩니다.

AI 에이전트가 이미 있다면, 이렇게 맡기세요

OMO가 아직 설치되지 않았다면 OMO에게 부탁할 수는 없으니, 위의 직접 설치하기 명령을 따라 하세요. Claude Code, ChatGPT 등 다른 AI 도구가 이미 있다면 아래 문장을 그대로 붙여넣어 도움을 받을 수 있습니다. 

내 컴퓨터는 Omarchy(Arch Linux)야. OMO 코딩 에이전트를 설치해줘.

/login 인증 절차를 초보자인 나에게 차근차근 설명해줘.
명령은 한 줄씩 알려주고, 각 명령이 무엇을 하는지도 설명해줘.
02 · 필수

한국어 입력기 설치

리눅스에서 한글을 치려면 입력기 프로그램이 필요합니다. Fcitx5는 입력기 프로그램이며, 한글 엔진을 함께 설치하면 Ctrl + Space로 한/영을 전환할 수 있습니다. 한국어 사용자라면 반드시 진행하세요.

시작하기 전에

이 안내서가 맞는 환경인지 확인하세요

이 스크립트는 Arch Linux 계열을 대상으로 합니다. Omarchy가 있으면 Omarchy의 패키지 명령을 사용하고, 그 외 Arch 환경에서는 pacman을 사용합니다.

  • 터미널에서 관리자 암호를 입력할 수 있어야 합니다.
  • Wayland 또는 X11 그래픽 세션 안에서 실행해야 합니다.
  • 기존 Fcitx5 프로필이 있으면 날짜가 붙은 백업 파일을 만듭니다.
직접 설치하기 1단계

스크립트를 준비합니다

먼저 이 안내서의 저장소를 받으세요. 안의 install-fcitx5-hangul.sh를 그대로 사용하세요. 

git clone https://github.com/yelixir-dev/omarchy-starter.git
cd omarchy-starter
chmod +x install-fcitx5-hangul.sh

위 링크를 눌러 브라우저로 스크립트만 내려받았다면 보통 다운로드 폴더에 저장됩니다. 

cd ~/Downloads
chmod +x install-fcitx5-hangul.sh
직접 설치하기 2단계

설치 스크립트를 실행합니다

설치 중 관리자 암호를 묻으면 현재 사용자의 암호를 입력하세요. 이미 설치된 패키지는 다시 설치하지 않습니다. 

./install-fcitx5-hangul.sh

스크립트는 다음 작업을 순서대로 수행합니다.

  1. fcitx5, GTK·Qt 연동 모듈과 한글 엔진, 설정 도구를 설치합니다.
  2. 현재 프로필을 profile.bak.날짜-시간.임의문자 형식으로 충돌 없이 백업합니다.
  3. Fcitx5가 꺼져 있으면 현재 세션에서 시작합니다.
  4. 영문 키보드와 한글 입력기를 기본 그룹에 등록하고 저장합니다.
  5. X11 세션이면 필요한 입력기 환경 변수를 별도의 파일에 저장합니다.
  6. 등록 결과에 hangul이 있는지 확인합니다.
직접 설치하기 3단계

한글로 전환합니다

새 설치에서는 Fcitx5의 기본 전환키인 Ctrl + Space를 누르세요. 기존 설정에서 전환키를 바꾼 적이 있다면 fcitx5-configtool의 전역 옵션에서 현재 전환키를 확인할 수 있습니다. 

영문 키 입력: gksrmf
한글 조합 결과: 한글
전환해도 영문만 입력될 때 새로 설치한 입력기 환경을 아직 실행 중인 앱이 읽지 못했을 수 있습니다. 먼저 앱을 완전히 종료했다가 다시 열고, 그래도 같으면 로그아웃 후 다시 로그인하세요.

설치 상태를 확인합니다

아래 명령으로 패키지와 입력기 그룹을 확인할 수 있습니다.

자주 막히는 지점

관리자 암호를 입력할 수 없습니다

03 · 선택

2019년형 및 이전 Intel Mac 팜 리젝션

팜 리젝션은 타이핑하는 동안 손바닥이 트랙패드에 닿아도 커서가 움직이지 않게 막는 기능입니다. 2019년형 및 이전 Intel Mac에서는 내장 트랙패드가 시스템에 "외장"으로 잘못 알려지는 경우가 있어 이 기능이 꺼져 있을 수 있습니다. 필요 여부는 출시 연도보다 MacBookAir8,2 같은 모델 식별자와 실제 분류 상태로 판단하는 편이 더 정확합니다.

이 장비에서 확인한 원인 2019년형 MacBookAir8,2의 내장 트랙패드가 T2 가상 USB를 거치며 external로 잘못 분류됐습니다. 그래서 Hyprland 설정은 켜져 있어도 libinput 상태는 Disable-w-typing: n/a였습니다.
직접 설치하기 1단계

내 Mac에도 필요한지 확인합니다

Apple 트랙패드 항목에서 Disable-w-typing: n/a가 보이면 이 스크립트의 대상입니다. 이미 enabled라면 설치하지 않아도 됩니다. 

omarchy pkg add libinput-tools
libinput list-devices

모델 식별자는 다음 명령으로 확인합니다.

cat /sys/class/dmi/id/product_name

변경 내용을 먼저 확인합니다(드라이런)

./install-intel-mac-palm-rejection.sh --dry-run

출력에 Apple 트랙패드, USB ID와 현재 분류가 표시돼야 합니다.

직접 설치하기 3단계

04 · 선택

VPN 설치하고 함께 쓰기

여기서 VPN은 두 가지를 뜻합니다. 하나는 내 기기끼리 연결하는 VPN(Tailscale)이고, 다른 하나는 인터넷 출구를 바꾸는 VPN(NordVPN)입니다. 이름은 같지만 하는 일이 완전히 다르고, 올바르게 설치하면 둘을 동시에 쓸 수 있습니다. 이 장에서는 각각 설치한 뒤, 충돌 없이 함께 쓰는 방법까지 알아봅니다.

04-1 · Tailscale

Tailscale 설치

Tailscale은 내 PC, 노트북, 휴대폰을 하나의 사설 네트워크로 묶어 주는 서비스입니다. 가입만 하면 각 기기에 100.x.x.x 형태의 고정 주소가 생기고, 카페 Wi-Fi에서도 집에 있는 PC나 다른 나라의 서버에 그 주소로 바로 접속할 수 있습니다. 이 안내서의 작성자는 이 기능으로 다른 방의 구형 노트북(ThinkPad T420) 파일 서버에 접속합니다.

왜 설치하나요? 원격으로 내 다른 기기에 접속하거나, 기기끼리 파일을 공유하거나, AI 에이전트가 내 다른 컴퓨터를 관리하게 하려면 가장 쉬운 방법이기 때문입니다.

직접 설치하기

설치하고 내 계정에 연결합니다

터미널에서 한 줄씩 실행하세요.

omarchy pkg add tailscale
sudo systemctl enable --now tailscaled
sudo tailscale up --accept-routes=false

마지막 명령을 실행하면 브라우저가 열리며 로그인 화면이 나타납니다. Google 계정 등으로 로그인하면 이 컴퓨터가 내 네트워크에 등록됩니다. --accept-routes=false는 다른 기기가 알려주는 경로를 자동으로 받지 않겠다는 안전 옵션입니다.

연결됐는지 확인합니다.

tailscale status
tailscale ping <다른-기기-이름>

04-2 · NordVPN

NordVPN 설치

NordVPN은 인터넷 트래픽 전체를 다른 나라의 서버로 보내는 서비스입니다. 연결하면 내 공인 IP 주소가 그 나라의 주소로 바뀝니다. 지역 제한 서비스를 이용하거나 공용 Wi-Fi에서 트래픽을 보호할 때 사용합니다.

이 안내서에서는 NordVPN의 자체 앱(nordvpn 명령)이 아니라 리눅스 기본 네트워크 도구인 NetworkManager의 OpenVPN 프로필로 설치합니다. 자체 앱은 Tailscale과 충돌할 수 있기 때문입니다(다음 섹션에서 설명).

직접 설치하기 1단계

OpenVPN 지원을 설치하고 설정 파일을 가져옵니다

omarchy pkg add networkmanager-openvpn

NordVPN 공식 서버 목록에서 원하는 나라의 .ovpn 파일을 내려받아 NetworkManager에 가져옵니다. 

nmcli connection import type openvpn file /path/to/jp878.nordvpn.com.udp.ovpn

가져온 프로필은 자동 연결을 끄고, VPN 사용 중 일반 IPv6는 차단합니다.

nmcli connection modify nordvpn-omo-split connection.autoconnect no
nmcli connection modify nordvpn-omo-split +ipv6.routes "::/0 type=blackhole"

프로필 이름은 가져오기 결과에 따라 달라집니다.

직접 설치하기 2단계

서비스 자격증명을 저장합니다

2023년 6월부터 NordVPN 계정 이메일/비밀번호는 OpenVPN 연결에 사용할 수 없습니다. Nord Account에서 Set up NordVPN manually → Service credentials의 Username과 Password를 사용해야 합니다.

아래 명령은 비밀번호를 화면에 표시하지 않고 프로필에 저장합니다 (root만 읽을 수 있는 시스템 파일에 보관합니다). 

sudo bash -c 'read -s -p "Service password: " p; echo; \
  nmcli connection modify uuid "프로필 UUID" vpn.secrets "password=$p"'

먼저 프로필 편집기에서 서비스 Username도 넣어 두세요.

nmcli connection edit uuid "프로필 UUID"
# 편집기 안에서:
#   set vpn.user-name <서비스 Username>
#   save persistent
#   quit
직접 설치하기 3단계

단축 명령을 만들어 켜고 끕니다

~/.bashrc 맨 아래에 두 줄을 추가하면 vpnon, vpnoff로 켜고 끌 수 있습니다. 

alias vpnon='nmcli connection up uuid "프로필 UUID"'
alias vpnoff='nmcli --wait 25 connection down uuid "프로필 UUID"'

새 터미널을 열거나 source ~/.bashrc 후 사용하세요.

04-3 · 주의점

Tailscale과 NordVPN을 함께 설치할 때 주의할 점

두 프로그램을 아무 방법으로나 같이 켜면 네트워크 전체가 끊길 수 있습니다. 둘 다 인터넷 경로와 방화벽을 바꾸는 프로그램이라 서로의 설정을 덮어쓰기 때문입니다. 아래 세 가지는 피하세요.

하지 말아야 할 것
  • NordVPN 자체 앱(nordvpn 명령) + Tailscale 동시 사용: 앱이 라우팅과 방화벽 규칙을 직접 바꿔 Tailscale과 충돌합니다. 실제로 시스템이 먹통이 돼 재설치한 사례가 있습니다.
  • Tailscale exit node 사용: NordVPN과 동시에 쓸 수 없습니다. tailscale up에 exit node 옵션을 주지 마세요.
  • Nord Meshnet 켜기: Tailscale과 같은 100.64.0.0/10 주소 대역을 써서 주소가 겹칩니다.
이 안내서에서 검증한 안전한 조합은 Tailscale(기기 연결 전용) + NetworkManager OpenVPN 프로필 하나입니다. 이 구성에는 kill switch가 없어서 NordVPN이 끊기면 일반 인터넷으로 바로 돌아갑니다(fail-open). Tailscale 원격 관리를 위한 의도된 동작이지만, VPN이 항상 유지되어야 하는 사생활 요구에는 맞지 않습니다.
04-4 · 함께 쓰기

Tailscale과 NordVPN을 함께 쓰는 방법

왜 둘 다 쓰나요? 목적이 다르기 때문입니다. Tailscale로는 내 기기(파일 서버 등)에 접속하고, NordVPN으로는 나머지 인터넷을 원하는 나라의 서버를 통해 이용합니다. 둘을 같이 켜면 "삼바 파일 서버는 Tailscale로 접속하면서, 웹서핑은 일본 서버로"가 동시에 됩니다.

충돌을 피하는 원리는 단순합니다. Tailscale은 100.x.x.x 같은 자기 기기 주소만 관리하고, NordVPN은 NetworkManager 프로필로만 올려 나머지 인터넷만 담당하게 합니다. 이 안내서 작성자의 컴퓨터에서 실제로 검증했습니다. NordVPN을 켠 상태에서도 Tailscale ping과 파일 서버 접속이 그대로 동작하고, NordVPN을 끄면 일반 인터넷으로 즉시 돌아옵니다.

직접 확인하기

분리 동작을 확인합니다

NordVPN을 켠 상태에서 아래 명령을 실행해 보세요.

curl https://api.ipify.org          # NordVPN 서버 IP가 나와야 함
tailscale ping <다른-기기-이름>     # Tailscale은 그대로 유지
ip route get 100.76.206.87          # table 52, tailscale0 경로 확인

연결을 끄면(vpnoff) 일반 인터넷으로 바로 돌아오고 Tailscale은 끊기지 않습니다.

GitHub 정리용

이 폴더에 들어 있는 파일

  • omarchy-starter.html: 지금 보고 있는 설치 안내서
  • install-fcitx5-hangul.sh: Fcitx5 한글 설치 스크립트
  • install-intel-mac-palm-rejection.sh: Apple 트랙패드 분류 수정 스크립트
  • install-fcitx5-bar-indicator.sh: 상태바 입력 언어(K/E) 표시 설치 스크립트
  • install-vpn-bar-toggles.sh: 상태바 VPN 토글 아이콘 설치 스크립트(설치된 것만 감지해 추가)
  • install-kakaotalk-bottles.sh: Bottles 카카오톡 설치 스크립트
  • patch-kakaotalk-korean-input.sh: 기존 카카오톡의 한글 입력창 네모 표시 패치
  • install-screenshot-shortcuts.sh: Mac 스타일 캡처 단축키와 상태바 버튼 설치 스크립트
  • DESIGN.md: 문서의 색상, 타이포그래피, 접근성 기준
  • manage-vpn-bypass-routes.sh: VPN을 우회할 추가 IP/CIDR 관리 도구
  • vpn-bypass-routes.conf.example: 우회 주소 설정 예시
  • assets/: 안내서에 들어가는 화면 사진(상태바 아이콘 등)

omarchy-starter.html은 화면 사진까지 내장한 단일 파일이라, 이 파일 하나만 공유해도 그대로 열립니다.
